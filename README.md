# World Cup 2026 Interactive Wall Chart

GitHub Pages-ready app.

## Upload instructions

1. Create a new GitHub repository, for example `world-cup-wall-chart`.
2. Upload all files from this folder to the repository root:
   - `index.html`
   - `manifest.json`
   - `icon-192.png`
   - `icon-512.png`
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/root**, then save.
6. Your public app link will be:

   `https://YOUR-GITHUB-USERNAME.github.io/world-cup-wall-chart/`

The app saves scores in the browser on each device. Use the Export/Import tools inside the app to move data between phones or computers.
